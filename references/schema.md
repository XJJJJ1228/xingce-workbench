# 行测工作台 · 数据规范（所有生成内容必须严格遵守）

## 一、题目对象 Question

```js
{
  id: "yy-ldtk-001",          // 全局唯一，规则：模块前缀-题型缩写-三位序号
  module: "言语理解",          // 固定枚举：言语理解 / 判断推理 / 资料分析 / 数量关系 / 常识判断
  type: "逻辑填空",            // 小题型，见下方题型表（必须严格使用表内名称）
  subtype: "实词辨析",         // 可选，更细一层（如 实词辨析/成语辨析/主旨概括/增长率…）
  difficulty: 2,              // 1=易 2=中 3=难
  stem: "题干正文……",         // 字符串，不含选项
  options: ["A．……", "B．……", "C．……", "D．……"],  // 4 个选项，带 "A．" 前缀（用全角点）
  answer: "B",                // 单个大写字母 A/B/C/D
  analysis: "【解析】……",      // 详细解析：含思路、关键词/公式、排除理由、结论，150-400 字
  tags: ["成语辨析", "语境呼应"], // 2-4 个知识点标签
  passage: "",                // 资料分析专用：共享材料文字/表格（Markdown 表格或纯文本）；其他题型为 ""
  groupId: "",                // 资料分析：同一篇材料的题共用，如 "ziliao-01"；其他为 ""
  figure: "",                 // 图形推理/几何题可选：一段 SVG 代码（不含 xml 头），或 "" 
  source: "模拟精编"           // 固定写 "模拟精编" 或 "真题改编"
}
```

### 模块 / 小题型枚举（必须完全一致）

| 模块 | 小题型（type） |
|---|---|
| 言语理解 | 逻辑填空、片段阅读、语句表达 |
| 判断推理 | 图形推理、定义判断、类比推理、逻辑判断 |
| 资料分析 | 文字型、表格型、图形型、综合型 |
| 数量关系 | 数学运算（subtype 用：工程问题/行程问题/排列组合/概率问题/最值问题/容斥原理/经济利润/几何问题/浓度问题/年龄问题/数列问题/周期日期/统筹问题/基础应用题） |
| 常识判断 | 政治常识、法律常识、经济常识、科技常识、人文历史、地理国情、管理公文、生活常识 |

### 各模块 id 前缀
- 言语理解 → `yy-`
- 判断推理 → `pd-`（图推 pd-txtl-001 / 定义 pd-dy-001 / 类比 pd-lb-001 / 逻辑 pd-lj-001）
- 资料分析 → `zl-`
- 数量关系 → `sl-`
- 常识判断 → `cs-`

## 二、积累卡片对象 Card

```js
{
  id: "cy-001",
  category: "成语",        // 枚举：成语 / 实词 / 政治常识 / 时事政治
  title: "南辕北辙",        // 词条名
  summary: "想往南走，车子却向北开。比喻行动和目的相反。",   // 一句话核心
  detail: "详细解释、出处、感情色彩、搭配对象、常见误用……", // 100-250 字
  example: "例句……",       // 例句或应用场景
  confuse: ["背道而驰", "分道扬镳"],  // 易混淆词（可为空数组）
  tags: ["高频", "易误用"],
  star: false              // 用户是否标星，运行时维护
}
```

## 三、文件输出格式（务必严格）

每个数据文件都是 **纯 JS**，格式如下（不要 JSON，不要 export，不要 require）：

```js
window.BANK_DATA = window.BANK_DATA || [];
window.BANK_DATA.push(
  { ...题目对象... },
  { ...题目对象... }
);
```

卡片文件：

```js
window.CARD_DATA = window.CARD_DATA || [];
window.CARD_DATA.push(
  { ...卡片对象... }
);
```

文件命名：
- `app/data/bank-yanyan.js`
- `app/data/bank-panduan.js`
- `app/data/bank-ziliao.js`
- `app/data/bank-shuliang.js`
- `app/data/bank-changshi.js`
- `app/data/cards-yanyan.js`（成语 + 实词）
- `app/data/cards-zhengzhi.js`（政治常识 + 时事政治）

## 四、质量要求（硬性）

1. 题干、选项、答案、解析必须自洽，答案唯一且正确，解析能支撑该答案。
2. 解析必须"教方法"：点明切入点、关键词/公式、逐项排除理由，不能只写"故选B"。
3. 内容原创或真题改编，不得照抄受版权保护的大段真题原文；材料数据自行编造但需合理。
4. 中文标点规范，选项用 `A．` 全角点，全文不要出现未转义的单引号破坏 JS 字符串（用双引号包字符串，字符串内部如出现双引号请改成中文引号 “ ”）。
5. 每批写入 15-25 条，分多次追加，避免单次输出过长被截断。写完后用 `node -e "..."` 或 `node --check` 校验语法。
